# T20 International Cricket Data Analysis

This project performs data analysis on T20 International cricket datasets using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
The dataset includes:
- players_info.csv
- t20i_Batting_Card.csv
- t20i_Bowling_Card.csv
- t20i_Matches_Data.csv
- t20i_Partnership_Card.csv

## Analysis Performed
- Top batsmen analysis
- Bowling economy analysis
- All-rounder impact score
- Player consistency analysis
- Partnership performance

## Key Insights
The project identifies top-performing players and analyzes batting, bowling, and all-rounder contributions in T20 cricket.
